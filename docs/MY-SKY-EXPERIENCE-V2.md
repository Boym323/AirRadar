# My Sky Experience V2 — retired

This implementation brief documents the retired Mobile Spotter `/spotter` surface. The page, its browser-local My Sky state, foreground alerts and Spotter-specific geometry were removed in the approved 2026-10-18 feature-retirement batch. The shared radar, watchlist, aircraft history, `/api/logbook/summary`, database history and global geolocation security policy remain. No browser storage or database rows were cleared by the retirement.
