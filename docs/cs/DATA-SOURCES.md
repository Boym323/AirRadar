# Zdroje dat

Lokální zdroj tvoří `readsb`; jeho data jsou odlišná od volitelných síťových
zdrojů ADSB.lol, ADSBHub a OGN. Původ každého externího údaje musí zůstat
rozlišitelný a veřejné výstupy nesmí zveřejňovat citlivé údaje přijímače.

Dodržujte podmínky licencí a atribuce jednotlivých providerů. ATC data jsou
pravděpodobné poziční shody, nikoli potvrzení naladěné frekvence.

Podrobnosti o původu, bezpečnosti a licencích jsou v
[anglické verzi](../DATA-SOURCES.md).
