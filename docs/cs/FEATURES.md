# Funkce a routy

Tento soubor je český přehled funkcí a rout. Kanonický seznam je generován z
`docs/features.registry.json`; při změně Next.js stránky nebo API routy se musí
nejprve aktualizovat registr a spustit `npm run features:generate`.

Hlavní veřejná rozhraní zahrnují živý snapshot `/api/aircraft`, SSE
`/api/stream`, health a diagnostické endpointy, historii, statistiky, vyhledávání
a watchlist. Přesný aktuální seznam je v [anglické verzi](../FEATURES.md).
