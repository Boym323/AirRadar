# API kontrakt Runway Public Rollout V1

`buildRunwayPublicRolloutDecision()` přijímá configured mode, effective mode, Runway readiness a Runway graduation calibration. Vrací verzované odvozené rozhodnutí obsahující stav, readiness, manual-review eligibility, public-active flag, požadavek na explicitní změnu konfigurace a blockery.

Funkce není HTTP API a ve V1 se přímo nevystavuje veřejným klientům.
