# Předpoklady Runway Public Rollout V1

V1 předpokládá, že existující graduation vrstva zůstává jedinou autoritou pro effective policy a existující Runway Advisory zůstává jedinou autoritou pro validitu konkrétní veřejné predikce. Pokud se některý kontrakt změní, rollout V1 se má před dalším použitím znovu posoudit.
