# Boundary Runway Public Rollout V1

Rollout model se záměrně nevolá z veřejného aircraft route ani z Predictive Operations Center route. Tyto endpointy nadále používají existující Runway advisory builder a efektivní policy vynucenou graduation guardem.

Oddělení rollout rozhodnutí od veřejných serializerů zabraňuje tomu, aby se provozní doporučení k readiness samo stalo publikačním mechanismem.
