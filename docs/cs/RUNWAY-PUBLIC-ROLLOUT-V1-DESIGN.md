# Návrh Runway Public Rollout V1

Runway rollout decision záměrně kopíruje ETA Public Rollout V1 místo zavedení obecného multi-capability mutation frameworku. Explicitní V1 pro každou capability drží auditovatelnou vazbu mezi readiness evidencí, záměrem operátora a fail-closed chováním, protože jednotlivé predictive capability stále používají odlišnou truth a quality semantiku.

Sdílenou abstrakci lze zvážit později pouze tehdy, pokud zachová capability-specific boundary a neumožní automatické povýšení.
