# Slovník Runway Public Rollout V1

- configured mode: operátorem zvolený záměr capability.
- effective mode: configured záměr po runtime readiness enforcementu.
- manual review eligible: signál graduation calibration, že existující readiness je PASS nad kompletní evidencí.
- public active: popisný stav vyžadující configured/effective PUBLIC a PASS.
- fail closed: veřejný záměr existuje, ale efektivní public eligibility je potlačená.
