# Provoz Runway Public Rollout V1

Provozně V1 poskytuje pouze decision kontrakt. Produkční aktivace zůstává samostatnou explicitní configuration/deployment akcí po review. Runtime readiness zůstává průběžně autoritativní i po aktivaci, takže pozdější regrese potlačí veřejnou eligibility, i když configured záměr zůstává PUBLIC.
