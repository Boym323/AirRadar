# Očekávaný výsledek Runway Public Rollout V1

Po merge umí AirRadar popsat, zda základní Runway stále sbírá evidenci, je připravená k explicitnímu review konfigurace operátorem, je aktivně public pod existujícím guardem, je fail-closed po regresi readiness nebo je vypnutá. Z tohoto popisu neplyne žádná automatická produkční akce.
