# Poznámky k testování Runway Public Rollout V1

Unit testy pokrývají SHADOW readiness, explicitní PUBLIC aktivaci, regresi readiness, DISABLED chování a zachování blockerů. Boundary testy ověřují absenci persistence/network/environment vedlejších efektů a potvrzují, že veřejné routy nadále závisí na existujícím Runway Advisory guardu, nikoli na rollout doporučení.
