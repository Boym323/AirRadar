# AirRadar V6 — vyřazený 3D radar a zachované testy leteckých médií

Volitelný 3D radar, terén, modely letadel, licencovaný GLB loader a test 3D zařízení popsané v historickém akceptačním plánu byly vyřazeny ve schválené dávce z 18. 10. 2026. Jejich runtime kód, stahování, GPU testy a browser gate byly odstraněny.

Letecká média zůstávají samostatnou funkcí: oficiální vložené přehrávače YouTube-nocookie vzniknou až po akci uživatele, libovolné URL přehrávačů se odmítají a při nedostupnosti vložení zůstává přímý odkaz na původní zdroj. Aktivní produkční CI nadále ověřuje souhlas, přesnou adresu iframe a fallback pro letecká média i oddělený Prezentační režim.
