# Vizuální systém

Vizuální změny mají používat sdílené komponenty `components/ui-primitives.tsx`
a sémantické tokeny. Nesmí zvyšovat rozpočet vizuálního dluhu. Po změně je
nutné spustit `npm run visual:check` a produkční desktopovou i mobilní
prohlídku podle vývojových pravidel.

Kompletní tokeny, layout, přístupnost a screenshotové kontroly jsou v
[anglické verzi](../VISUAL-SYSTEM.md).
