# Veřejné měření T58 bez tokenu — V1

**Stav:** připravený kandidát implementace; produkční měření ani návrat databáze NEJSOU OVĚŘENY. Dokument nepovoluje nasazení ani archivování.

## Chování a zabezpečení

- `T57_PUBLIC_ONLY=1` aktivuje výslovný režim čtení bez tokenu nad stávajícími endpointy `/api/system/status` a `/api/system/runtime-performance`.
- Výchozí administrační režim T57 se nemění. Veřejné T58 nevolá `/api/watchlist/session`, nepoužívá cookies a nevyžaduje `T58_WATCHLIST_ADMIN_TOKEN`.
- Měření je omezené na intervalové CPU, RSS/heap, okna event loopu, veřejnou identitu buildu a základní health. **Neměří** privátní retenci, přesnou identitu procesu, major-GC, SQL cache, atribuci událostí ani forenzní Digital Twin.
- Administrativní zápisy i citlivé čtení zůstávají pod ochranou podepsané session. Úplné odstranění autentizace z veřejně přístupného serveru by bylo nebezpečné.
- Soukromý omezený journal zachovává přísná oprávnění. Záznamy veřejného a administračního režimu nelze kombinovat při pokračování. Kontrola reportu odmítá tajemství a identifikátory letadel.
- Hodinové měření používá sedm read-only částí a odmítá nedostatečné pokrytí, změny identity, chybějící okna nebo nedostupné API. Výsledek veřejného režimu může být jen `PASS_WITH_LIMITATIONS`, ne potvrzení administrační forenzní analýzy či rollbacku databáze.

## Ověření

1. Na stejném SHA spustit TypeScript, Vitest, testy veřejné projekce, kontrolu lokalizace, CodeQL a všechny browser/release-preview brány.
2. GitHub workflow `T58 Public Preflight` ověří veřejné GET v produkci bez změny služby. Dosavadní `T58 Production Soak` zůstane výslovně ručně spouštěným hodinovým sledováním v omezeném veřejném režimu.
3. Ověřit skutečný nasazený commit a zdraví služby. Úspěšné veřejné měření neprokazuje Prisma mapování, funkční zálohu/obnovu ani privátní diagnostiky providerů.
4. Po nezávislé read-only kontrole PostgreSQL kompatibility a doloženém rollbacku posoudit finální release. V2 zůstává samostatná.

## Zbývající blokéry

- Produkční read-only mapování katalogu Prisma a vyzkoušená záloha/obnova či rollback nejsou ověřeny.
- Souběh privilegovaných workerů nelze prokázat anonymní telemetrií.
- Finální sloučení kódu, produkční kontrola a GitHub Archived jsou samostatná rozhodnutí. Tato změna jejich dokončením není.
