# Záznamy architektonických rozhodnutí

[English](../../decisions/README.md)

Záznam vysvětluje, **proč** platí trvalé omezení. Nenahrazuje aktuální kód, [architekturu](../ARCHITECTURE.md) ani [runtime invarianty](../RUNTIME-INVARIANTS.md). Pro zásadní rozhodnutí udržuj jeden stručný dokument bez opakování celé implementace.

## Přijatá rozhodnutí

- [ADR-0001 — Jeden vlastník live stavu a readsb → RAM → SSE](ADR-0001-single-live-owner.md).

## Údržba

Nové rozhodnutí obsahuje kontext, vybranou a odmítnutou variantu, důsledky a odkazy na důkazy. Nahrazená rozhodnutí označ, historii tiše nepřepisuj. Udržuj český protějšek a neuváděj zastarávající verze ani tvrzení „právě nasazeno“.
