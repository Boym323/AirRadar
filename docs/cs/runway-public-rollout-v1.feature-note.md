# Poznámka k Runway Public Rollout V1

Runway má nově explicitní provozní rollout stavový automat podle ověřeného ETA rollout kontraktu. Rozlišuje sběr evidence, připravenost k ruční explicitní změně na PUBLIC, aktivní veřejné vystavení, fail-closed návrat a vypnutý stav, aniž by měnil existující publikační guard Runway Advisory V1.
