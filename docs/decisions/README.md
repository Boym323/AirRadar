# Architecture decision records

[Česky](../cs/decisions/README.md)

A decision record explains **why** a durable constraint exists. It does not replace current code, [architecture](../ARCHITECTURE.md) or [runtime invariants](../RUNTIME-INVARIANTS.md). Keep one short record per genuinely consequential decision; do not repeat implementation prose.

## Accepted decisions

- [ADR-0001 — Single live-state owner and readsb → RAM → SSE](ADR-0001-single-live-owner.md).

## Maintenance

New decisions state the context, chosen option, rejected alternative, consequences and evidence links. Mark superseded decisions rather than silently rewriting history. Keep matching Czech documents and avoid version numbers or "currently deployed" claims.
