# AirRadar Wiki

AirRadar je radar ADS-B v tmavém režimu pro lokální přijímač `readsb`. Živý
stav zůstává v RAM a do prohlížeče se doručuje přes Server-Sent Events (SSE).
PostgreSQL ukládá vzorkovanou historii, referenční data a denní statistiky.
