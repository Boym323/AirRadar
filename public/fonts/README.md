# Map label glyphs

Open Sans Semibold SDF glyphs from the [MapLibre demo tiles](https://github.com/maplibre/demotiles/tree/gh-pages/font/Open%20Sans%20Semibold), served locally so airport and ATC labels need no external font service or CSP exception.

The bundled ranges cover Latin-1, Latin Extended-A/B and general punctuation used by airport identifiers and Czech ATC names. Additional scripts require their corresponding glyph ranges. The font is distributed under the Apache 2.0 license included in `LICENSE-Open-Sans.txt`; upstream font source and license: [OpenMapTiles Open Sans](https://github.com/openmaptiles/fonts/tree/master/open-sans).
